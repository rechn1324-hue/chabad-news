# חב״ד בזמן אמת

אתר חדשות שמתעדכן לבד, מסביב לשעון: חדשות חב״ד, ישראל ופוליטיקה, העולם, מבזקים מטלגרם וסרטונים מיוטיוב – ואיזור ילדים עם משחקים.

## איך זה עובד

- **איסוף אוטומטי:** כל 15 דקות רץ ב-GitHub רובוט (`.github/workflows/update.yml`) שמריץ את `scripts/fetch-news.mjs`.
  הוא אוסף כותרות מכל המקורות, שומר אותן ב-`data/news.json` ומפרסם את האתר מחדש. המחשב שלכם לא צריך להיות דלוק.
- **מקורות:** COL, חב״ד אינפו, COLlive, Anash, CrownHeights.info, Chabad.org, ynet, N12, וואלה, מעריב, ישראל היום, ערוץ 14, ערוץ 7,
  בחדרי חרדים, JDN, Times of Israel, Jerusalem Post ועוד, חדשות גוגל, ערוצי טלגרם (עמית סגל, N12 צ׳אט הכתבים, ynet) וערוצי יוטיוב (JEM ועוד).
  הרשימה המלאה ב-`scripts/sources.mjs`.
- **כל כותרת מקשרת לכתבה המקורית.** האתר מציג כותרת ותקציר קצר בלבד.

## ניהול האתר (בלי לגעת בקוד)

נכנסים ל-`admin.html` באתר (קישור "כניסת מנהל" בתחתית העמוד). שם אפשר:

- לפרסם כתבות משלכם (עם תמונה או סרטון)
- להעלות פרסומות: בראש האתר, בין החדשות, בצד העמוד או באיזור הילדים, כולל תאריך סיום אוטומטי
- לפרסם מבזקים, ולהטמיע ציוצים מ-X (טוויטר) לפי קישור
- להצמיד כתבה לראש העמוד או להסתיר כתבה
- להוסיף מקורות חדשים (ערוץ טלגרם, אתר עם RSS, ערוץ יוטיוב) או לכבות מקורות קיימים
- לשנות את שם האתר, להוסיף פס "דחוף", לחסום מילים, ולבחור אם להציג תמונות מאתרי החדשות הכלליים

הכניסה דורשת "מפתח גישה" של GitHub (Fine-grained token) עם הרשאת **Contents: Read and write** למאגר הזה בלבד.
ההוראות המלאות מופיעות במסך הכניסה. השינויים מופיעים באתר בתוך דקה-שתיים.

## יוטיוב (לא חובה)

אם הסרטונים מיוטיוב לא נאספים, אפשר להוסיף מפתח חינמי של YouTube Data API:
ב-GitHub נכנסים ל-Settings ← Secrets and variables ← Actions ← New repository secret, בשם `YOUTUBE_API_KEY`.

## הרצה מקומית

```
node scripts/fetch-news.mjs
python -m http.server 8077
```

ואז פותחים את http://localhost:8077

## מבנה

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html`, `assets/site.js` | העמוד הראשי |
| `post.html` | עמוד לכתבה שנכתבה באתר |
| `admin.html`, `assets/admin.js` | עמוד הניהול |
| `kids/` | איזור הילדים: טנק המבצעים, זיכרון, בלוני אותיות, חידון, סביבון, צביעה |
| `data/news.json` | החדשות שנאספו (נכתב אוטומטית) |
| `data/content.json` | התוכן שלכם: כתבות, פרסומות, מבזקים, הגדרות |
| `uploads/` | תמונות שהועלו מעמוד הניהול |
| `scripts/` | הרובוט שאוסף את החדשות |
