# חב״ד בזמן אמת

אתר חדשות שמתעדכן לבד, מסביב לשעון: חדשות חב״ד, שמחות וקהילה, ישראל ופוליטיקה, העולם, מבזקים מטלגרם, סטוריז, שורטס – ואיזור ילדים עם משחקים וטבלת שיאים.

## איך זה עובד

- **איסוף אוטומטי:** כל 15 דקות רץ ב-GitHub רובוט (`.github/workflows/update.yml`) שמריץ את `scripts/fetch-news.mjs`.
  הוא אוסף מכל המקורות, מסנן כפילויות ועדכונים משעממים, משלים תמונות ותקצירים, ומפרסם את האתר מחדש. המחשב שלכם לא צריך להיות דלוק.
- **מקורות:** COL, חב״ד אינפו (כולל שמחות, אירועים, ברוך דיין האמת, וידאו וילדים), COLlive, Anash, CrownHeights.info, Chabad.org,
  ynet, N12, וואלה, מעריב, ישראל היום, ערוץ 14, ערוץ 7, בחדרי חרדים, JDN, Times of Israel, Jerusalem Post ועוד, חדשות גוגל,
  ערוצי טלגרם (עמית סגל, N12 צ׳אט הכתבים, ynet) ויוטיוב (כיכר השבת, JEM, ערוץ חב״ד לילדים). הרשימה המלאה ב-`scripts/sources.mjs`.
- **אתר שחוסם את שרתי GitHub** נאסף אוטומטית דרך חדשות גוגל.
- **כפילויות:** סיפור שמופיע בכמה אתרים מוצג פעם אחת, עם "דווח גם ב…".
- **כל כתבה** נפתחת קודם בתצוגה מקדימה באתר (תמונות + טקסט מורחב), עם כפתור להמשך הקריאה באתר המקורי וכפתורי שיתוף.
- **שיתוף:** לכל כתבה יש עמוד שיתוף (`s/<id>.html`) עם תמונה וכותרת, כך שבוואטסאפ ובפייסבוק רואים תצוגה יפה – והקישור מוביל לאתר שלנו.

## ניהול האתר (בלי לגעת בקוד)

נכנסים ל-`admin.html` (קישור "כניסת מנהל" בתחתית האתר). שם אפשר:

- כתבות משלכם (עם תמונה או סרטון), פרסומות (4 מיקומים, כולל תאריך סיום), מבזקים וציוצים מ-X
- **סטוריז** משלכם – מופיעים ראשונים בעיגולים שבראש האתר
- הצמדה או הסתרה של כתבות שנאספו אוטומטית
- **איזור הילדים:** קישור (וואטסאפ/טופס) לשליחת יצירות, וגלריית יצירות שאתם מאשרים ומעלים
- **טבלת שיאים:** הסתרת שמות לא מתאימים
- מקורות: הוספת ערוץ טלגרם / אתר RSS / ערוץ יוטיוב, או כיבוי מקור
- הגדרות: שם האתר, פס "דחוף", קישור לערוץ הוואטסאפ של האתר, סינון נושאים משעממים, מילים חסומות, תמונות מאתרים כלליים

הכניסה דורשת "מפתח גישה" של GitHub (Fine-grained token) עם הרשאת **Contents: Read and write** למאגר הזה בלבד.
ההוראות המלאות מופיעות במסך הכניסה. השינויים מופיעים באתר בתוך דקה-שתיים.

## הערות

- **וואטסאפ:** לערוצי וואטסאפ אין דרך פתוחה למשוך מהם הודעות. אפשר להעתיק מבזק משם לעמוד הניהול, או להוסיף את ערוץ הטלגרם המקביל.
- **טבלת השיאים** של הילדים נשלחת דרך ntfy.sh ונאספת לקובץ `data/scores.json` בכל עדכון.
- **יוטיוב:** אם הסרטונים לא נאספים, אפשר להוסיף מפתח חינמי של YouTube Data API בשם `YOUTUBE_API_KEY` ב-Settings ← Secrets and variables ← Actions.

## הרצה מקומית

```
node scripts/fetch-news.mjs
python -m http.server 8077
```

ואז פותחים את http://localhost:8077

## מבנה

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html`, `assets/site.js` | העמוד הראשי: סטוריז, פיד אינסופי, תצוגה מקדימה, מבזקים |
| `shorts.html`, `assets/shorts.js` | שורטס – גלילה בין סרטונים (`?c=kids` לסרטוני ילדים) |
| `post.html` | עמוד לכתבה שנכתבה באתר |
| `admin.html`, `assets/admin.js` | עמוד הניהול |
| `kids/` | איזור הילדים: משחקים, טבלת שיאים, סרטונים וגלריית יצירות |
| `data/news.json` | החדשות שנאספו (נכתב אוטומטית) |
| `data/previews.json` | טקסט מורחב ותמונות לתצוגה המקדימה (אוטומטי) |
| `data/kids.json`, `data/scores.json` | סרטוני ילדים ושיאים (אוטומטי) |
| `data/content.json` | התוכן שלכם: כתבות, פרסומות, מבזקים, סטוריז, גלריה, הגדרות |
| `uploads/` | תמונות שהועלו מעמוד הניהול |
| `scripts/` | הרובוט שאוסף את החדשות |
