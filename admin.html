כניסה לניהול

הניהול שומר את השינויים ישירות במאגר של האתר ב-GitHub. כדי להיכנס צריך "מפתח גישה" (Token) – יוצרים אותו פעם אחת, וזה לוקח כשתי דקות.

  1. היכנסו לחשבון ה-GitHub שלכם ופתחו את דף יצירת המפתח.
  2. בשדה Token name כתבו למשל: ניהול האתר. בשדה Expiration בחרו תוקף ארוך (למשל שנה).
  3. תחת Repository access בחרו Only select repositories ובחרו את המאגר chabad-news.
  4. תחת Permissions ← Repository permissions ← Contents בחרו Read and write.
  5. לחצו Generate token, העתיקו את המפתח שמתחיל ב-github_pat_ והדביקו אותו כאן.

המפתח נשמר רק בדפדפן שלכם ונשלח רק לשרתי GitHub. אל תשתפו אותו עם אף אחד.
